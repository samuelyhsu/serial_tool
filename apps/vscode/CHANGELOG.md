# 更新日志 · Changelog

本文件记录「Serial Tool」扩展的变更。
格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循
[语义化版本](https://semver.org/lang/zh-CN/)。

## [0.3.0] - 2026-09-17

### 新增

- 活动栏的端口列表显示你在面板里给端口起的备注名（如 `温控板 · COM3 · CH340 (1A86:7523)`），
  改完立刻生效，不必重开 VS Code。
- 波特率候选从 32 档补全到 51 档（50 ~ 4000000），汇总 Windows / Linux 的标准档与
  CP210x、CH340 芯片手册里的档位，另含 ESP8266 上电日志用的 74880。

### 变更

- 波特率下拉点开总是列出全部档位，并高亮当前值；边打字边按开头数字筛选。
  此前框里是 115200 时点开只剩 115200 / 1152000 两项，想换档得先把值删掉。
  筛选时直接按 Enter 保留你输入的值，要选候选档先按 ↓。
- 波特率输入框去掉了加减微调按钮，滚轮也不再改值；只接受数字，粘贴 `921,600` 也能用。
- 去掉顶栏标题左侧的「S」图标，它只是装饰。
- 工具栏去掉了连接状态指示（圆点加文字），它与「打开 / 关闭串口」按钮重复。打开过程中
  按钮显示「打开中…」；自动重连期间按钮变成琥珀色，悬停可见「重连中…」，点它照旧会停止
  重连并关闭串口。
- 语言切换按钮的文字由「EN / 中文」改为「EN / CN」。
- 状态栏去掉了「端口 @ 波特率 8N1 · 流控」这段摘要，顶部工具栏上这些一直都显示着。

### 修复

- 调大日志缓冲容量后，面板隐藏再显示（比如切走标签页再切回来）不再只剩默认的 10000 条。
  此前扩展宿主那份缓冲始终按默认容量保留，重建出来的面板也会退回建面板时的容量。
- 面板隐藏再显示后，打开面板之后改过的设置不再退回原样。此前指令预设、主题、手动切换的
  界面语言、端口备注、各设备的串口参数等都会回到打开面板时的值，接着再改一次预设还会把
  之前改好的列表覆盖掉。在别的面板里改的设置，隐藏着的面板重新显示时也会跟上。

## [0.2.0] - 2026-09-13

首次发布到 VS Code Marketplace 与 Open VSX。

> **从 0.1.0 升级**：0.1.0 是以「串口助手 · Serial Assistant」
> （`samuelyhsu.web-serial-tool-vscode`）的名义随 GitHub Release 分发的，本版起扩展 ID
> 改为 `uplume.serial-tool`。两者的命令 ID 相同，同时装着会有一个激活失败 ——
> 请先卸载旧版再安装。旧版存下的偏好不会带过来。

### 新增

- 面板左下角（状态栏最左侧）显示版本号，反馈问题时一眼能看出用的是哪一版。
- 日志缓冲容量可在接收区工具栏调整：默认 10000 条，不少于 1000，不设上限。
  列表最多渲染最新 1000 行（原先 600 行），更早的记录在列表顶部标明条数，
  点「保存」可导出完整日志。

### 变更

- 扩展改名为 Serial Tool，名称与简介跟随 VS Code 显示语言，中文环境下显示为
  「串口助手」；商店页补上英文说明。
- 「清空」改为按两下：第一下按钮变成「确认清空？」，3 秒内没有再按就复原。
  这一步不可撤销，会丢掉缓冲里的全部采集数据与统计，而按钮就紧挨着「保存日志」。
- 多条发送的底部压成一行，矮窗口下能多显示几条预设；「全部停止」只在有周期任务
  运行时出现。

### 修复

- 「清空」现在会连扩展宿主保留的那份日志历史一起丢。此前它只清了面板这一侧，
  宿主的环形缓冲毫不知情 —— 面板一隐藏再显示，快照回放就把清掉的日志连同
  统计原样带了回来。
- 英文 VS Code 里，标签页标题、状态栏、端口选择框与端口视图不再显示中文，
  跟随 VS Code 的显示语言。
- 手动切换的界面语言不再在面板隐藏又显示之后被改回去。
- 矮窗口下单条发送区不再被挤到溢出（HEX 报错行出现时尤其明显）。
- 面板里的西文字体跟随 VS Code 的工作台 / 编辑器字体设置（此前变量名写错，从未生效）。

## [0.1.0] - 2026-08-30

首个版本。

- 一个面板 = 一条会话 = 一个端口，可同时开多个面板各连一口。
- 串口会话跑在扩展宿主进程：面板被隐藏、切去看代码，串口不会断，周期发送照跑。
- 活动栏端口视图：点一个端口直接连上；已连接的口标注占用者。
- HEX / 文本双视图、接收分帧（原样 / 空闲超时 / 按换行）、校验和、周期发送、
  发送预设、断线自动重连。
- 设备身份带序列号，换 USB 口也认得出来；备注与波特率按设备记忆。
- 状态栏在写队列有积压时显示积压字节数，作为背压的直接观测点。
- 设置存在 VS Code 的 globalState 里，可随 Settings Sync 跨机器同步。

> 本版尚未发布到 Marketplace，只随 GitHub Release 分发 VSIX。
> 扩展形态下的人工验收清单（见仓库 README「测试」一节）尚未完整走过一遍。
